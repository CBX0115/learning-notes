# 爬虫是什么，怎么实现？

爬虫（Web Crawler）本质上就是一个**自动化程序**：模拟浏览器向网站发 HTTP 请求，拿到返回的 HTML/JSON 数据，从中解析出你想要的内容，再存起来，然后循环往复。



**实现语言没有硬性限制**，但生态差别很大：

| 语言               | 适用场景             | 核心库/框架                                                  |
| :----------------- | :------------------- | :----------------------------------------------------------- |
| **Python**（首选） | 90% 的爬虫场景       | `requests`、`BeautifulSoup`、`lxml`、`parsel`、Scrapy、Playwright |
| JavaScript/Node    | 需要深度模拟浏览器时 | Puppeteer、Playwright                                        |
| Java / Go          | 大规模分布式爬虫     | jsoup、colly                                                 |

**需要掌握的技术**：

1. **HTTP 基础**——GET/POST 请求、请求头（User-Agent、Cookie）、状态码
2. **网页解析**——CSS 选择器、XPath（提取 HTML 里的数据）
3. **抓包分析**——用浏览器 F12 的 Network 面板找出网页背后的 JSON 接口（**这是最重要的技能**，很多网站数据是接口返回的，直接调接口比解析 HTML 简单得多）
4. **动态渲染处理**——Selenium / Playwright 驱动真实浏览器，对付 JS 渲染的页面
5. **反爬应对**——请求频率控制、随机延时、代理 IP、Cookie 池
6. **数据存储**——CSV / JSON 文件，或 SQLite / MySQL



## 实战

### 爬边伯贤动态

1. **选源**：微博超话/话题（粉丝站实时搬运他的动态，最推荐）> 贴吧 > 新闻媒体；Instagram 限制严，不建议

2. **抓包**：Chrome 打开 `m.weibo.cn` 搜索"边伯贤”，F12 → Network 找到 `api/container/getIndex` 这个 JSON 接口

   1. 搜索完成后，停在搜索结果页

   2. 在这个页面按 **F12** 打开开发者工具

   3. 勾选 `Fetch/XHR` 过滤器 + `Keep log`（你已经勾上了，很好）

   4. 关键一步：**再按 F5 刷新一次这个页面**

   5. 在你刚才打开的那条 `getIndex` 请求右边面板里：

      1. 点 **Headers** 标签
      2. 往下找到 **Request Headers** 区域
      3. 找到 **`Cookie:`** 那一行，选中它**右侧的全部内容**（从 `SUB=` 开始到行尾），按 Ctrl+C

      ⚠️ 只复制 Cookie 的**值**，不要复制 URL，也不要复制 `Cookie:` 这几个字。不过即使复制了，脚本也能去掉。

3. **代码**：脚本实现了 请求接口 → 解析 JSON（提取时间、内容、点赞、评论、链接）→ 清洗 HTML 标签 → 按热度排序 → 存为 `baekhyun_weibo.json`







**`getIndex` 是手机版 `m.weibo.cn` 的接口，而电脑版是`s.weibo.com`**——两边用的是完全不同的接口体系
